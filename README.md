# Сравнительный анализ алгоритмов обнаружения аномалий

Код и результаты курсовой работы по машинному обучению. 
В проекте реализован пайплайн оценки unsupervised-алгоритмов (Isolation Forest, LOF, One-Class SVM, KNN, Elliptic Envelope, Mahalanobis) на пяти табличных наборах данных.

## Состав репозитория
* `anomaly_detection_final.ipynb` — исходный код экспериментов.
* `anomaly_detection_results_final.csv` — агрегированные метрики качества.
* `best_params_frequency.csv`, `wilcoxon_pr_auc.csv` — статистика гиперпараметров и тесты значимости.
* `*.png` — визуализации результатов.
